# 🎓 Arsip Kode Tugas Akhir

Arsip lengkap seluruh kode yang digunakan dalam penyelesaian Tugas Akhir (skripsi) — mulai dari scraping data hingga aplikasi Android.

## 📌 Deskripsi

Repo ini berisi seluruh tahapan pengerjaan tugas akhir dalam satu tempat:

| Folder | Isi |
|---|---|
| `Kode Scraping/` | Kode pengambilan data (scraping) |
| `Preprocessing/` | Kode pra-pemrosesan data |
| `Skema Model/` | Skema/skrip pelatihan model |
| `Aplikasi Android` | Kode/berkas aplikasi Android hasil akhir [`Web-Scrapper`](https://github.com/dewamardana/Mushroom-Classification) |

## ⚙️ Alur Kerja (Pipeline)

```
Scraping data → Preprocessing → Training model → Aplikasi Android
```
